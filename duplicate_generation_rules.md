# Duplicate Generation Rules

SPIDER includes controlled duplicate records generated using seven rule categories.

These rules were designed to represent common duplicate patterns found in person-information systems, CRM platforms, QA test environments, and entity resolution workflows.

## Rule Categories

1. Email variation
2. Phone number variation
3. Last name variation
4. Address variation
5. Nickname variation
6. First name spelling variation
7. Shared account variation

## Purpose of Controlled Duplicates

The controlled duplicate records support repeatable testing and benchmarking of entity resolution and duplicate detection methods.

Because the duplicates are generated using known rule categories and cluster identifiers, researchers and practitioners can evaluate matching accuracy, recall, precision, and rule-level performance.
