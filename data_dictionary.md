# Data Dictionary

This file provides a high-level description of the SPIDER dataset fields.

The full dataset is not hosted in this GitHub repository. Please access the official Version 2 dataset through Figshare.

Official Dataset DOI: https://doi.org/10.6084/m9.figshare.29595599.v2

## Field Categories

The dataset contains synthetic person-information fields used for entity resolution and duplicate detection research.

Field categories include:

- Record identifiers
- Name fields
- Contact fields
- Address fields
- Date-related fields
- Duplicate rule indicators
- Cluster identifiers

## Record Identifiers

These fields uniquely identify records in the dataset and support traceability during entity resolution testing.

## Name Fields

Name-related fields represent synthetic person names and may include variations used for duplicate generation.

## Contact Fields

Contact-related fields may include synthetic email addresses and phone numbers.

## Address Fields

Address-related fields represent synthetic location information used for matching and validation scenarios.

## Duplicate Rule Indicators

Duplicate rule fields identify the type of controlled duplicate variation applied to a record.

## Cluster Identifiers

Cluster identifiers support evaluation of entity resolution results by grouping records that represent the same synthetic entity.
