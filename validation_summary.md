# Validation Summary

The SPIDER dataset was validated for realism, consistency, and usefulness in entity resolution and duplicate detection testing.

## Validation Areas

Validation included checks related to:

- State and ZIP-code consistency
- Phone-number area-code patterns
- Email and name alignment
- Duplicate-cluster structure
- Controlled duplicate rule coverage
- Baseline entity-resolution testing

## Dataset Realism

The dataset was designed to reflect realistic synthetic person-information patterns while avoiding the use of real personal information.

## Duplicate Structure

Controlled duplicate records were generated using known rule categories and cluster identifiers. This allows users to evaluate entity resolution results against known duplicate groups.

## Baseline Testing

Baseline entity-resolution testing was performed to confirm that the dataset can support evaluation of matching approaches.
