# Dataset Overview

SPIDER stands for Synthetic Person Information Dataset for Entity Resolution.

SPIDER is a synthetic person information dataset created for entity resolution, duplicate detection, record linkage, and data-quality testing research.

The dataset contains 50,000 synthetic person records:

- 40,000 base records
- 10,000 controlled duplicate records

The dataset was designed to support repeatable evaluation of duplicate detection algorithms without using real personal information.
